Catálogo de REP

Sube un Excel con los datos de cada representante — al crear un caso, con solo escribir el código se completan zona, gerente de zona y teléfono automáticamente.

Importar desde Excel

Si el archivo tiene varias hojas, se toma la que se llama REC. Esa hoja debe tener columnas con estos nombres (no importa el orden ni mayúsculas/minúsculas): Codigo, Zona, Gerente de zona, Contacto, Sector, Días Mora, Saldo Local. Si un código ya existe en el catálogo, se actualiza con los datos nuevos.
